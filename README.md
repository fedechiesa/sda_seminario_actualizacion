# Seminario de Actualización — IA & Data Science

Repositorio correspondiente a la materia **Seminario de Actualización (SDA)** de la Tecnicatura en Inteligencia Artificial y Data Science.

El repositorio reúne el material teórico, ejemplos en Python y ejercicios utilizados durante la cursada.

## Contenidos

Durante la materia se trabajan conceptos relacionados con el desarrollo de sistemas basados en agentes de inteligencia artificial.

Entre los temas vistos hasta el momento se encuentran:

- Fundamentos de Python aplicados a la materia.
- Fundamentos de agentes autónomos.
- Implementación de agentes en Python.
- Arquitecturas de sistemas multiagente.
- Coordinación entre agentes.
- Arquitecturas centralizadas, distribuidas e híbridas.
- Implementaciones multiagente con LangChain.
- Implementaciones multiagente con LangGraph.
